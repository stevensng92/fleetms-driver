# Triage labels

The skills speak in five triage roles. In this repo's local tracker a role is
the value of the `Status:` line in a ticket file.

| Role in mattpocock/skills | `Status:` value here | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Steven needs to evaluate this ticket |
| `needs-info` | `needs-info` | Waiting for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, an agent can build it unattended |
| `ready-for-human` | `ready-for-human` | Needs a person (a phone test, a dashboard, a decision) |
| `wontfix` | `wontfix` | Will not be done |
